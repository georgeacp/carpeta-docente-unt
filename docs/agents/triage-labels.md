# Triage Labels

Las skills utilizan los siguientes roles canónicos y nombres de etiquetas:

| Rol de la skill | Etiqueta en GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Pendiente de evaluación por el mantenedor. |
| `needs-info` | `needs-info` | Falta información del solicitante. |
| `ready-for-agent` | `ready-for-agent` | Especificado y listo para un agente. |
| `ready-for-human` | `ready-for-human` | Requiere implementación humana. |
| `wontfix` | `wontfix` | No se llevará a cabo. |

Cuando una skill mencione un rol, aplicar la etiqueta de esta tabla.
Crear únicamente las etiquetas que falten; conservar las existentes.
